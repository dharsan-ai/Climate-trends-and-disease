
## 🌍 Climate Trends & Disease Outbreak Prediction

A machine learning project that models the relationship between climate variability and infectious disease outbreaks using PCA, SVR, and Random Forest algorithms.

## 🎯 Project Overview

This project integrates mathematical foundations from linear algebra and calculus with machine learning to develop a predictive framework for climate-driven disease outbreaks.

## 📐 Mathematical Foundations

### Linear Algebra
- **Principal Component Analysis (PCA)**: Eigenvalue decomposition for dimensionality reduction
- **Matrix Operations**: Feature transformation and projection

### Calculus
- **Rate-of-change analysis**: Understanding climate variable dynamics
- **Optimization**: Model parameter tuning (gradient descent)

## 🤖 Machine Learning Models

| Model | Purpose | Mathematical Basis |
|-------|---------|-------------------|
| **PCA** | Dimensionality reduction | Eigenvectors, Covariance matrix |
| **SVR** | Temperature forecasting | Kernel functions, Optimization |
| **Random Forest** | Outbreak classification | Ensemble learning, Decision trees |

## 📊 Dataset Features

| Feature | Description | Range |
|---------|-------------|-------|
| Temperature (°C) | Daily average temperature | 15-35°C |
| Humidity (%) | Daily average humidity | 40-90% |
| Rainfall (mm) | Daily precipitation | 0-50mm |
| Wind Speed (km/h) | Daily average wind | 0-30 km/h |
| Disease Cases | Number of reported cases | 0-500 |
| Outbreak Flag | Binary classification | 0 or 1 |
